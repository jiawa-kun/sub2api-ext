新建排行活动

设置活动后，先预览获奖名单，再确认发放额度。

1. 活动信息

选择榜单后，系统会按照活动时间统计排名。

取排序后的前 N 名参与奖励计算，不代表每个名次都必须发奖。
填写 0 表示不限制预算。

2. 活动时间与结算方式

每日、每周、每月均结算上一个完整自然周期，时区固定为上海。

3. 奖励方案

单个名次和名次区间分开填写；区间奖励表示范围内每个人都获得相同额度。
